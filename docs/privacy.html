Privacy Policy

Clippa is a personal automation tool. It cuts short clips from public Twitch and YouTube streams and uploads them to its owner's own YouTube channel. It has no other users and no sign-up.

What Google data it uses

With the owner's permission, Clippa uses the YouTube Data API scope youtube.upload only to upload videos to the owner's own channel. It does not read, store or share any other Google account data, and it does not access anyone else's account.

How data is stored

The OAuth credentials are kept as encrypted GitHub Actions secrets in the owner's repository and are used only when the upload job runs. Clippa keeps a list of clips it has posted (title, source link, date, video link) in the same repository. Nothing is sold, shared with third parties, or used for advertising.

Public data it reads

To choose clips, Clippa reads public information from the Twitch and YouTube APIs: clip titles, view counts, channel names and public video segments. Every uploaded clip credits its source channel.

Removing access

The owner can revoke Clippa's access at any time at myaccount.google.com/permissions. Clippa's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions or removal requests: open an issue at github.com/qiiiiyr/clippa/issues.
